# 2026-11-12

## Instagram sahifasini navbar bo‘yicha ajratish

Bitta Instagram sahifa akkaunt, media, nashr, tahlil va ssenariyani birga ushlardi. Endi har biri alohida navbar sahifasi.

| Sahifa | Path | Ruxsat |
|--------|------|--------|
| Akkauntlar | `/app/instagram` | `INSTAGRAM` |
| Media | `/app/instagram/media` | `IG_MEDIA` |
| Nashr | `/app/instagram/publish` | `IG_PUBLISH` |
| Tahlil | `/app/instagram/insights` | `IG_INSIGHTS` |
| Ssenariya | `/app/instagram/scenario` | `IG_SCENARIO` |

- Liquibase `009` CREATE/INSERT (ALTER yo‘q). `INSTAGRAM` ruxsati bor foydalanuvchilarga yangi sahifalar nusxalanadi. `PLATFORM_ADMIN` avvalgidek hammasini ko‘radi.
- Akkaunt ro‘yxati API istalgan shu sahifadan ochiladi. Qolgan API o‘z sahifasiga bog‘langan. Ssenariya oxirgi tahlilni o‘qiy oladi.
- Tanlangan akkaunt `sessionStorage` da saqlanadi, sahifalar o‘rtasida bir xil qoladi.
- Navda `/app/instagram` aniq moslashadi — media ochiqligida Akkauntlar yonmaydi.

## Media + nashr, tahlil + ssenariya

- Nashr alohida sahifa emas: Media dagi «Post qo‘shish» dialog ochadi. API `IG_MEDIA`.
- Ssenariya alohida sahifa emas: Tahlil sahifasining pastida. API `IG_INSIGHTS`.
- Liquibase `010`: `IG_PUBLISH` va `IG_SCENARIO` `enabled=false`.
